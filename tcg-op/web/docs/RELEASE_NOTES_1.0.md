# TCG OP 1.0 · Nakamura Twins Studio

## Cambios de interfaz
- Nueva pantalla de inicio como centro de operaciones TCG.
- Identidad visual refinada en azul noche, violeta, lila y rosa.
- Nuevo icono PWA con Tsuki y Yami.
- Biblioteca SVG de iconos para escáner, colección, inventario, catálogo, cámara, galería, QR, respaldo y ajustes.
- Avatares chibi de Tsuki y Yami integrados en el flujo de trabajo.
- Tsuki acompaña visualmente la lectura OCR y la búsqueda de impresiones; el progreso ya no muestra porcentajes ficticios.
- Yami aparece en el módulo de valoración; el motor de precios y sus fuentes no se modificaron.
- La pantalla de inicio muestra unidades, registros y valor estimado desde el inventario local.
- Ajustes de Gemini conservados: clave personal local o configuración privada de servidor existente.

## Alcance y compatibilidad
- Se conserva la lógica de identificación, OCR, catálogos, inventario, precios, QR, respaldo y funciones Netlify.
- No se incluyen cambios de proveedor ni de lógica de IA en esta versión.
- PWA y caché del service worker actualizadas a v1.0.
